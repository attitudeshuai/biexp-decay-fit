# 难点与测试对应

## 难点 1：两个时间常数要分开搜

推理轴：数值方法

落在推理路径上的哪里：双指数模型对两个时间常数是非线性的，给定两个时间常数后幅度与基线才是线性的。原实现只取对数做单指数回归，慢成分整个丢掉。正确做法是在 (τ1, τ2) 上做二维搜索：先粗网格定位，再分别细化；两个时间常数拉不开（比值约 2.7）时也不能退化成一个指数。

对应测试：test_tau_pair_matches_independent_fit、test_near_degenerate_components_resolved

## 难点 2：限幅点要整点剔除

推理轴：数据口径

落在推理路径上的哪里：探测器上限以内的读数才代表真实波形，顶到上限的点是被限幅的。这些点如果留在拟合里，会把快成分的幅度与时间常数都拉偏。原实现全算进去了。

对应测试：test_saturated_points_removed、test_second_curve_with_other_rates

## 难点 3：基线、比值与残差的定义

推理轴：业务规则

落在推理路径上的哪里：模型里有一个与时间无关的本底 c，它和慢成分的长尾互相牵扯；报告里的幅度比要等于 a1/a2，残差按自由度 n-4 换算成 rmse。原实现既没有基线，也没有这几栏。

对应测试：test_baseline_and_ratio_consistent、test_rmse_near_noise_level

## 跨运行状态（重复运行与不污染）

同一份记录重复运行，报告逐字节一致（不能写时间戳）；运行失败时不能覆盖上一次的报告：先写临时文件再原子替换，非法记录以退出码 2 收场且不落文件。对应测试：test_rerun_produces_identical_bytes、test_failed_run_keeps_previous_report。

非法输入另有 test_invalid_data_rejected_without_output 单独覆盖（点太少、时间不单调、上限非正、剔除后有效点不足），输出结构由 test_report_schema_and_rounding 覆盖。

## 权重口径

10 条测试：时间常数对 0.15、难分离用例 0.14、限幅点剔除 0.11、第二套曲线 0.11、残差 0.07、基线与比值 0.07、非法记录 0.11、输出契约 0.08、重复运行 0.08、失败不覆盖 0.08，和为 1。

## 定标依据（自检用）

判分侧独立做 (τ1, τ2) 网格加黄金分割细化（网格密度与细化路径与参考解不同），同一份曲线上两者参数一致到 1% 内。本地实测参考解 1.000000、缺陷版 0.000000；缺陷版是单指数对数回归、不剔限幅点、报告带时间戳且缺基线/比值/残差几栏，10 条全挂。
